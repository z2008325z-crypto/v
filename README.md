# يحب

## التشغيل على GitHub Pages
1. اعمل repo جديد واسمه مثلا yahib.
2. ارفع الملفات: index.html, style.css, script.js (و database.rules.json للمرجع فقط).
3. من Settings ← Pages اختار Branch: main و Root.
4. الموقع هيكون على: https://USERNAME.github.io/yahib/

## Firebase
- Authentication: فعّل Email/Password و Google.
- Authentication ← Settings ← Authorized domains: ضيف USERNAME.github.io.
- Realtime Database: انسخ محتوى database.rules.json والصقه في Rules ثم Publish.
- حساب الأدمن: سجل دخول من الموقع بالإيميل abmen@gmail.com (أو أنشئه من Authentication ← Users). أول دخول بيفعل صلاحيات الأدمن تلقائيا.

## أمان مهم
غيّر كلمة سر الأدمن فورا، لأنها اتكتبت في محادثة. كلمة السر ماتتحطش في الكود أبدا.
